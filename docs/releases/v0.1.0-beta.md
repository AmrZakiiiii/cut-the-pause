# Cut The Pause v0.1.0-beta

The first public beta brings the local-first silence-editing workflow to Apple
Silicon Macs. Import an MP4 or MOV, analyze speech gaps, review the proposed
cuts, and export only after the timeline looks right.

## Highlights

- Local speech-gap analysis with the bundled Silero VAD model and an
  energy-based fallback when the model is unavailable.
- Reviewable detected ranges with per-cut toggles, waveform timeline review,
  manual cut ranges, and adjustable detection settings.
- Named detection/export presets, analysis and export history, and saved export
  checkpoints for pause/resume workflows.
- 10-bit HEVC Main 10 MP4 delivery output or an explicitly selected ProRes-based
  MOV editing master.
- Live export progress plus safe cancellation for analysis and export.
- A self-contained macOS package with FFmpeg, FFprobe, and the Silero model
  bundled in the app artifact.

## Supported package

- Apple Silicon (`osx-arm64`) only.
- macOS 13.0 or newer.
- Download `CutThePause-macos-arm64.zip` and
  `CutThePause-macos-arm64.zip.sha256` from this release.

Verify the checksum before opening the app:

```bash
shasum -a 256 -c CutThePause-macos-arm64.zip.sha256
```

The beta is unsigned and not notarized. After verification, extract the ZIP,
move `Cut The Pause.app` out of the archive, and use Finder’s **right-click (or
Control-click) → Open** flow on first launch. Do not disable Gatekeeper
globally. Intel Macs are not supported by this artifact.
